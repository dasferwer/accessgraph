# Проверки

Пройдены 7 тестов с PostgreSQL 17 и Redis, включая конкурентное создание цикла,
проверку прогретого кеша после отзыва и недоступность Redis.
Прошли линтер и проверка форматирования. Docker API проверен через `scripts/demo.py`:
после удаления участника команды следующий запрос к вложенному документу
вернул отказ за 6,79 мс. Это единичное локальное измерение, не оценка перцентилей
и не гарантированная задержка сервиса под нагрузкой.
